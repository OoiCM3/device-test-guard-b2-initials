# Contributing

This fictional workshop repository uses short-lived branches and pull requests.

1. Create a branch named `feature/<issue-number>-<short-name>` or `fix/<issue-number>-<short-name>`.
2. Keep commits focused and use an imperative subject.
3. Run `python -m unittest discover -s tests -v`.
4. Never add credentials, personal data, customer data, Intel material, or proprietary specifications.
5. Open a pull request, link the Issue, request review, and merge only after checks pass.
